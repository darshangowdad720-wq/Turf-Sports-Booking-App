
# Turf Sports Slot Booking App

## About the Project
The Turf Sports Slot Booking App is an Android application designed to help users book sports turf slots easily.

## Features
- View available turf slots
- Select booking dates
- Choose preferred time slots
- Book sports facilities
- Manage bookings

## Technologies Used
- Java
- XML
- Android Studio
- SQLite Database

## Modules
1. User Interface
2. Slot Selection
3. Booking Management
4. Database Management
